# dct — CLAUDE.md pointer (attached by `dct init`)

With your consent, `dct init` attaches the short block below the `---`
separator to your personal `~/.claude/CLAUDE.md`, between dct's managed
markers: re-runs refresh it, your own content outside the markers is never
touched. To add it by hand, paste only the block below the separator.

The block is a pointer, not the guide. The full reference ships as
`dct/assets/dct-reference.md`, which `dct init` installs as
`~/.claude/dct-reference.md`; the assistant reads it on demand. Do not paste
the reference into `CLAUDE.md`, and do not turn the path below into an import:
a rules file is loaded in every session.

---

## Cross-project tracking (dct)

dct tracks items, checkpoints, changelog, sprints and handoffs (MCP server `dct`, skills `/track`, `/pickup` …).
Before using dct beyond the skills' own triggers, read `~/.claude/dct-reference.md`.
